Platform

Everything between your build server and the player.

Three boring things, done properly. We are deliberately small: no marketplace, no launcher, no ads.

/static

Asset edge

Textures, bundles and web builds served from hot storage with immutable URLs and long-lived caching.

/patch

Delta patches

Binary diffs between versions, chunked and resumable. Players download what changed, not the whole game.

/media

Trailers & devlogs

Adaptive video segments for press kits and store pages, with signed links for embargoed material.

Pipeline

One command from CI to every player.

  • Staged rollouts — 5%, 25%, everyone. Roll back in seconds.
  • Content-addressed — identical chunks are stored once.
  • Signed manifests — clients verify every file before install.
  • Plain HTTPS — works behind any firewall, no custom ports.
# push a new build
$ ak push ./build --channel beta
✓ 1,284 chunks · 312 new · 2.1 GB uploaded
✓ manifest signed v0.9.14-beta

# roll it out
$ ak release v0.9.14-beta --to 25%
✓ live on channel beta · 25% of players

# something broke? undo.
$ ak rollback beta
✓ reverted to v0.9.13 in 4s
