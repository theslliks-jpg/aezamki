What this website collects

This website does not use cookies, analytics, tracking pixels or third-party scripts. Our web servers keep standard access logs (IP address, time, requested path, user agent) for up to 14 days for security and troubleshooting, then delete them.

Delivery traffic

Files delivered on behalf of studios are served under agreements with those studios. We process only the technical data needed to deliver a file and do not build profiles of players.

Sharing

We do not sell or rent personal data. We disclose data only where required by applicable law.

Your rights

Because we hold no accounts for visitors of this website, there is generally no personal data to access or delete beyond short-lived server logs, which expire automatically.
